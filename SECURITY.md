# Security

## What and why

If you find a problem that could put someone at risk, please tell us
privately, so it can be fixed before it's widely known. For example:

- a tool writes, replaces or deletes a file it shouldn't, or replaces one
  without backing it up first;
- something private ends up somewhere public, such as a customer ID inside a
  paint file;
- a tool runs something, or controls the mouse or keyboard, when it shouldn't.

Not sure whether it counts? Report it privately anyway. We'd rather hear about
it twice than not at all.

Ordinary bugs, like a logo in the wrong place, go in the
[issues](https://github.com/Aintologic/aintologic-iracing-paints/issues) as
usual.

## How to report a problem privately

1. Go to the [project's page](https://github.com/Aintologic/aintologic-iracing-paints)
   on GitHub.
2. Click the **Security and quality** tab. If you don't see it, it's in the
   **⋯** menu at the end of the row of tabs.
3. Click **Report a vulnerability**, fill in the form, and click
   **Submit report**.

Or go straight to the form:
[report a vulnerability](https://github.com/Aintologic/aintologic-iracing-paints/security/advisories/new).

Only you and the project's maintainers can see the report. You need a GitHub
account to send one.

Please don't put your iRacing password, customer ID or other private details in
a report. Nobody working on this project will ever ask for your iRacing
password.

## What "done" looks like

- You get a reply in the report itself. This is a small fan-made project, so
  there's no promised response time, but every report is read.
- The fix comes out in a new version, and the [change log](CHANGELOG.md) says
  what was fixed, without details that would help anyone take advantage of it.
- You're credited in the report, unless you'd rather not be.

Fixes go into the newest version only. If you're on an older one, update to
the newest release.

## For the AI agent

If you notice something while working that looks like a security problem,
stop and tell the person plainly what you found. Suggest a private report as
described above instead of a public issue, and never put their private
details into it.
